# TechViet HRMS — IT Business Analyst Portfolio

TechViet HRMS is a portfolio case study for an IT Business Analyst role. The project demonstrates how a mid-sized technology company can centralize fragmented HR operations across Recruitment, Onboarding, Employee Directory, and Performance Management.

## Project Structure

```text
HR_MANAGEMENT_SYSTEM/
├─ BA_PORTFOLIO_PACK/      # BA documentation and diagrams

```

## BA Documentation

Main BA artifacts are available in:

```text
BA_PORTFOLIO_PACK/DOCX_EXPORT/
```

Included DOCX files:

1. BRD
2. User Stories and Acceptance Criteria
3. Requirements Traceability Matrix
4. Business Rules and RBAC Matrix
5. Data Model and Data Dictionary
6. UAT Test Cases
7. RAID Log and Change Log

Additional markdown source files and diagrams are kept in `BA_PORTFOLIO_PACK/`.

## Prototype Modules

- Dashboard and HR metrics
- Recruitment / AI-assisted ATS
- Applications Box and candidate routing
- Recruitment Pipeline Kanban
- Interviews Calendar with room/time overlap validation
- Onboarding tracker and IT provisioning
- Employee Directory and scalable Org Chart
- Performance Management with KPI/OKR, review cycles, historical snapshots, and 9-box calibration

## Run Prototype Locally

```bash
cd techviet-hrms
npm install
npm run dev
```

## Build Prototype

```bash
cd techviet-hrms
npm run build
```

## Portfolio Positioning

This is an interactive BA validation prototype using mock data. It is not a production HRMS. The goal is to demonstrate business analysis thinking, requirements traceability, stakeholder workflows, RBAC, data consistency, UAT coverage, and prototype-based requirement validation.
