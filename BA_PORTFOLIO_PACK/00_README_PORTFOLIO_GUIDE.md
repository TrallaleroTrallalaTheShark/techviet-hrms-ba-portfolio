## Purpose

This pack is the main documentation source for the TechViet HRMS portfolio project. It demonstrates the full BA workflow from business problem discovery to requirements, process modeling, traceability, RBAC, data thinking, UAT planning, risk control, and prototype validation.

The pack is aligned with the interactive React prototype, including the latest updates for:

- AI-assisted recruitment with HR-approved rejection queue
- Interview calendar with same-room time-overlap conflict detection
- Recruitment-to-onboarding handoff with duplicate prevention by candidate ID
- Dynamic onboarding progress, task, and document tracking
- Employee Directory and scalable Org Chart with role-based visibility
- Performance Management with KPI/OKR creation, review cycles, historical snapshots, check-ins, and 9-box calibration
